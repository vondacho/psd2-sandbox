# Berlin-NextGenPSD2-sandbox
Why, what, how. Design, implementation and E2E testing of a NextGenPSD2/AISP/PISP compliant system

# Why
[Berlin Group NextGenPSD2](https://www.berlin-group.org/psd2-access-to-bank-accounts)

# What
[Implementation Guidelines](https://c2914bdb-1b7a-4d22-b792-c58ac5d6648e.usrfiles.com/ugd/c2914b_f7066c0ffa2e4242b8a25e7b31f1278a.pdf) that specify the XS2A interface in technical detail, including XML/JSON schemas

# How
This project should provide a sandbox that implements NextGenPSD2/XS2A on an AISP/PISP system.
